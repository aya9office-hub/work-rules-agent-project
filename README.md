# 就業規則・附属規程 構造チェックツール

## 目的
このツールは、就業規則と附属規程を横断して、構造上の問題点を確認するためのプロトタイプです。
主目的は法違反の断定ではなく、規程間の不整合、参照先の不足、用語ゆれ、委任条項の接続漏れなどの検出です。

旅費規程は通常のチェック対象から外しています。

## できること
- Word / PDF / txt / md のアップロード
- 就業規則・附属規程の横断チェック
- Word形式の報告書出力
- OpenAI APIキーがない場合は簡易ルールチェックで動作
- OpenAI APIキーがある場合はAIによる構造チェックを実行

## セットアップ
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt
copy .env.example .env
```

`.env` に OpenAI APIキーを設定します。APIキーなしでも簡易チェックは動きます。

```env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4.1-mini
```

## 起動
```bash
streamlit run app.py
```

ブラウザが開いたら、就業規則と附属規程をアップロードし、チェックを実行してください。

## 想定する入力
- 就業規則
- 賃金規程
- 育児・介護休業規程
- 退職金規程
- 企業型確定拠出年金規程
- その他、就業規則に接続する附属規程

## 出力
`就業規則_構造チェック報告書.docx`
